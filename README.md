This repository consists of Driver Tutorials from scratch in day wise section:
Day-1 This is the intro to character driver with init and exit
Day-2 Device register and get the major and minor number of it- Done by two options => direct (alloc_chrdev_region) and indirect method (MAKEDEV, register_chrdev_region)
Day-3 Assigning the device file by manual and automatic- Manual-> mknode permissions syntax after insmode and Automatic-> create class and device.
Day-4 Completing the driver with cdev and file operations for automatic device allocation code=> provides easy and fast output.
